BlueOffice Internal HR API - README

This API is for internal BlueOffice services only. It is not reachable
from the public internet.

Known internal peer services (informational - for the analytics team):
  - 127.0.0.1:3000            internal HR analytics dashboard (this host)
  - internal-api.blueoffice.local:5000   this API (self)

If you need another internal host added to this list, contact the
platform team - do not hardcode new hosts without review.
